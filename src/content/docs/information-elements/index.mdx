Информационные аспекты — восемь тематических областей, через которые в соционической модели описывают информацию. Аспект задаёт **тему**: например, время, отношение, структуру или телесное ощущение. Позиция функции в модели А описывает **характер обработки** этой темы у конкретного типа.

Ниже для каждого аспекта приведены основные смысловые ориентиры и пример различения в контексте. Одно слово может относиться к нескольким аспектам: значение определяется тем, о каком свойстве ситуации идёт речь. Эти описания не позволяют определить тип по отдельной реплике.
