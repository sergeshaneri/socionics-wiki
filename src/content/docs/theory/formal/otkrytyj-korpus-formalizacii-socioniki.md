Я собираю в одном репозитории материалы для формализации соционики: авторские определения и формулы, таблицы, исследовательские отчёты, вычислительные пакеты, проверки и рабочие главы. [Репозиторий socionics-formalization открыт на GitHub](https://github.com/sergeshaneri/socionics-formalization). Есть [английское описание](https://github.com/sergeshaneri/socionics-formalization/blob/main/README.en.md); большая часть исследовательских текстов пока написана на русском.

Одна из задач — описать связь между матрицей Адамара $H_{16}$, признаками Рейнина, формулами их поколений и перестановками модели А. В [текущем прототипе](https://github.com/sergeshaneri/socionics-formalization/blob/main/formalization/equivariant-8T9/FORMALIZATION.md) исследуется конкретная таблица шестнадцати моделей: соответствующие перестановки образуют группу $8T9\cong D_8\times C_2$ ($D_8$ — группа порядка 8), а столбцы $H_{16}$ дают базис функций на её элементах. Код проверяет конечные равенства на исходных данных. Это результат для выбранной таблицы и соглашений; общие теоремы и обоснование соционической интерпретации требуют отдельной работы.

## Что находится в репозитории

В корпусе сохранены исходные тексты, датированные исследования, таблицы, скрипты и результаты проверок. [README](https://github.com/sergeshaneri/socionics-formalization#readme) указывает точки входа и команды для воспроизведения; [исследовательский контекст](https://github.com/sergeshaneri/socionics-formalization/blob/main/HANDOFF.md) описывает постановку, ограничения результатов и открытые задачи.

Материалы имеют разный статус. Исходный текст фиксирует формулировку автора. Отчёт может содержать гипотезу или результат отдельного вычисления. Тест устанавливает выполнение утверждения на проверенных данных. Для математического доказательства нужны явно названные предпосылки и вывод из них. Известные расхождения и ограничения описаны рядом с материалами.

## Как работать с корпусом при помощи ИИ-агента

Репозиторий можно клонировать и открыть в [OpenCode](https://opencode.ai/docs/) или другом агенте, способном читать файлы и запускать проверки. Например:

```bash
git clone https://github.com/sergeshaneri/socionics-formalization.git
cd socionics-formalization
opencode
```

Команда `opencode` предполагает, что программа уже установлена по [официальной инструкции](https://opencode.ai/docs/). Для начала работы агенту можно дать конкретное задание:

> Прочитай `README.md`, `HANDOFF.md` и файлы, на которые они ссылаются. Выбери одно утверждение о признаках Рейнина или перестановках модели А. Укажи точный источник и область действия; отдели авторское определение от последующей формализации. Найди существующую проверку, запусти её, если окружение позволяет, и сообщи результат. Если утверждение установлено только для конечной таблицы, не называй его общей теоремой. Исходные документы не изменяй.

Другие подходящие задачи: сопоставить формулу с исходным файлом, воспроизвести вычисление из отчёта, проверить оба полюса признака на шестнадцати моделях, сформулировать недостающие условия для доказательства. Вывод агента следует сверять с источником и результатами выполнения кода.

OpenCode — открытый инструмент. В его [списке моделей](https://opencode.ai/docs/models/) можно выбрать вариант для работы; [OpenCode Zen](https://opencode.ai/docs/zen/) перечисляет и бесплатные модели. Доступность бесплатных вариантов и условия их использования могут меняться, другие модели могут тарифицироваться. Работа без платы за модель возможна при выборе доступного бесплатного варианта, но не для любой конфигурации OpenCode.

Если вы нашли неточность, укажите конкретный файл, формулу, принятые соглашения и воспроизводимый контрпример или расчёт. Такой разбор можно оформить в [Issues репозитория](https://github.com/sergeshaneri/socionics-formalization/issues).
